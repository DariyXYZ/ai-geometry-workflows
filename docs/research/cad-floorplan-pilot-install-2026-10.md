# Первые тесты генераторов планировок

Проверено 13 октября 2026 года на рабочем компьютере: Rhino 8, Revit 2023, Python 3.12, .NET SDK 10. Цель первой волны — сравнить жилой этаж, квартирографию и отдельную квартиру на одних и тех же исходных данных. Готовность к запуску и пригодность алгоритма для проекта — разные вопросы.

## Очередь для теста: от простого запуска к интеграции с Revit

## Что можно открыть сейчас

- **EBA:** дважды нажать `C:\VS Code\workfiles\research\floorplan-testing-2026-10\run-eba.cmd` или, пока сервер запущен, открыть `http://127.0.0.1:5127`. В приложении выбрать `rectangular-core` или `l-shaped-core`, нажать Generate и сравнить варианты.
- **FloorPlan6:** дважды нажать `C:\VS Code\workfiles\research\floorplan-testing-2026-10\run-floorplan6.cmd`. Начать с вкладки **Stage 4: Apartment Layout**, затем попробовать **Stage 3: Floor Layout**. Вкладка Stage 1 без пакета ArchiCAD показывает заглушку; для теста квартиры и этажа она не нужна.
- **PlanFinder:** перезапустить Rhino 8, затем найти PlanFinder и PlanFinderGH в установленном меню/Grasshopper. Если появится окно активации, пройти вход или включить пробный доступ в интерфейсе разработчика. Установка подтверждена через `Yak list`, запуск в Rhino пока не проверен.
- **Готовые результаты:** `C:\VS Code\workfiles\research\floorplan-testing-2026-10\outputs\` содержит JSON двух этажей EBA и PNG квартиры FloorPlan6.

Исходники EBA и FloorPlan6 находятся в `C:\VS Code\tools\floorplan-pilots\`. Они установлены отдельно от основного проекта и не меняют открытые модели Rhino/Revit.

## Проверка установки и следующий опыт

- EBA собран без предупреждений. 247 из 248 тестов прошли; один тест сравнивает окончания строк в JS-файле и падает на Windows. API сгенерировал 2 валидных варианта по запросу к локальному серверу.
- FloorPlan6 установлен в отдельное Python-окружение. Для запуска потребовался `PyYAML`, который импортируется кодом, но отсутствует в `requirements.txt`. Окно прошло проверку запуска без ArchiCAD; генерация квартиры и этажа проверена отдельно.
- PlanFinder установлен из каталога Yak. По [документации Rhino](https://developer.rhino3d.com/guides/yak/installing-and-managing-packages/) новый пакет загружается при следующем запуске Rhino.
- Rhino.Inside.Revit уже присутствует в каталоге дополнений Revit 2023. Совместимость текущего Refinery Toolkit с этим Revit не подтверждена; основной код репозитория [указывает Dynamo 3.0+](https://github.com/DynamoDS/RefineryToolkits).

Для предметного сравнения нужны 2–3 наших контура с ядром, входами и целевой квартирографией. Сравнивать число квартир по типам, реальные площади, выход к фасаду, доступ к коридору, пересечения, время расчёта и редактируемость в Rhino/Revit. Результат генератора пока считать эскизом, а не проверенной документацией по СП.
